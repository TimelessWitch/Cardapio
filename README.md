# Misturas 🥘

Planejador de cardápio semanal para organizar refeições e lista de compras.

## Funcionalidades

- **Cardápio semanal** com 12 slots (segunda a domingo, almoço e janta)
- **Geração automática** de pratos respeitando dificuldade por dia da semana
- **Lista de compras** agrupada por ingrediente base com soma de quantidades
- **Modo solo** — ajusta as quantidades pela metade
- Pratos difíceis só aparecem de sexta a domingo
